### 需要在真实浏览器中人工确认的步骤（NF8）

本机未安装 Chromium，故以下步骤待人工执行（不影响交付，产物本身已验证可执行）：

1. 断网后双击 `dist/装机助手.html`
2. 左侧选「CPU」→ 搜索 `7800x3d` → 点「选它」
3. 再选主板/显卡/内存/电源/机箱/散热器/硬盘
4. 故意选一个冲突配件（如 AM4 主板 + Intel CPU），确认：
   - 型号行出现 ⚠ 且**仍可点选**
   - 右栏出现 🔴 卡片，含原因与 `→ 建议`
   - 左栏 CPU 与主板**同时变红**
5. 点右栏「查看主板」确认跳转闭环
6. 保存两套方案 → 点「⚖对比」→ 确认只比型号/兼容性/功耗，**无价格**
7. 点「📤导出」→ 选 xlsx → 导出后确认无价格列
8. 关闭页面重新打开 → 确认配置仍在

## 开发过程中修复的缺陷统计

共 **15 个真实缺陷**，全部修复并补回归测试：

**产品代码（9 个）**
1. `enums.js` 对象键 `LGA2011-3` 未加引号 → 语法错误，脚本崩溃
2. `validate-data.mjs` 把 `radiatorSupport: []` 判为缺失 → 「不支持水冷」无法表达，会让 E8 误判
3. `enums.js` 的 `STATUS_ICONS` 缺 `info` 键 → 提示级品类界面无图标
4. `rules-data.js` 的 I1 未要求已选 CPU → 空配置下余量虚高误报
5. `search.js` 的 `applyConditionFilter` 丢弃无 condition 字段的记录 → 型号莫名消失
6. `store.js` 的 `update()` 在 mutator 之后置 dirty → 保存方案后仍显示未保存
7. `build.mjs` 用字符串形式做 `replace` → `$$` 被转义成 `$`，产物出现重复声明（SyntaxError）
8. `csv-to-json.mjs` 把模板示例行当真实数据 → 8 条脏数据
9. `validate-data.mjs` 不容忍 BOM → Windows 用户保存的 JSON 必崩

**测试代码（6 个）**：断言算错（漏算机箱风扇/硬盘功耗）、误用共享字段名 `formFactor` 跨品类校验、误把 GPU 显存类型当内存代数、`$$` 相关的正则误伤、`added` 语义理解错、A15 正则误伤合法文案

> 说明：产品代码缺陷按"修到对为止"处理；测试写错也一并修正，**未通过放宽标准来让测试变绿**。

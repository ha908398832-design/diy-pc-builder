# 装机助手

单文件离线网页版的 DIY 装机选配与兼容性校验工具。**双击 `dist/装机助手.html` 即用**，无需安装、断网可用。

## 它能做什么

- **选件**：内置 8 大品类共 300 个主流硬件型号，支持别名模糊搜索（`7800x3d`、`4070S`、`小雕` 都能搜到）
- **看参数**：44 个结构化字段；勾选 2~4 个型号可并排对比，差异项自动高亮
- **查兼容**：32 条规则自动校验，每条给出**原因**和**怎么改**
  - 🔴 17 条错误：插槽不符、内存代数不符、机箱装不下、显卡超长、电源瓦数/接口不足、无核显又无独显…
  - 🟡 11 条警告：电源余量 <20%、散热压不住、内存需降频、老主板要刷 BIOS、PCIe 降速…
  - 🔵 4 条提示：电源买太大、升级空间、平台末期、二手风险
- **算功耗**：CPU 取峰值功耗（不是标称 TDP），给出建议电源瓦数与余量
- **存方案 / 导出清单**：多方案保存对比；导出 xlsx / csv / 文本购物清单
- **可扩充**：用 CSV 模板自己加型号，支持覆盖 / 跳过 / 并存三种重名策略

> **只提示不拦截**：不兼容的型号照样能选中，软件只负责醒目提醒并在导出清单里标注。

## 快速开始

```bash
# 直接使用（推荐）
双击 dist/装机助手.html

# 从源码重新构建
node tools/gen-data-bundle.mjs    # 把 data/*.json 打包为 ES 模块
node tools/build.mjs              # 内联 CSS+JS+数据 → dist/装机助手.html

# 一键跑完全部门禁（规范生成 → 数据校验 → 构建 → 无价格门禁 → 全量测试）
node tools/gate.mjs
```

本项目**零依赖**，只用 Node.js 内置能力，无需 `npm install`。

## 目录结构

```
dist/装机助手.html       ← 最终交付物（单文件）

docs/开发计划.md          ← 可执行开发计划（48 个任务）
docs/验收记录.md          ← A1~A15 验收记录 + 缺陷清单

data/*.json              ← 8 品类硬件数据库（300 条）

schema/fields.js         ← 字段规范（单一数据源）
schema/hardware.schema.json  ← 由 fields.js 生成

src/core/                ← 纯逻辑（不接触 DOM，可完整单测）
  enums.js               枚举唯一来源（防字面量分裂）
  rules-data.js          32 条规则声明式注册表
  rules.js               规则引擎
  power.js               功耗计算
  status.js              状态灯汇总
  search.js              搜索/筛选/排序
  store.js               状态与持久化
  csv.js                 CSV 解析与合并
src/ui/
  render.js              纯函数渲染（数据 → HTML 字符串，可单测）
  app.js                 唯一接触 DOM 的层
  export.js              导出（含自写 xlsx 写入器）

tools/                   ← 构建、校验与门禁脚本
tests/                   ← 298 项测试
```

## 架构要点

**为什么核心逻辑写得像库**：`src/core/*` 与 `src/ui/render.js` 都是纯函数、不接触 DOM，所以 32 条规则、功耗计算、搜索、甚至**渲染输出**都能在 Node 里直接单测。只有 `app.js` 碰 DOM，且尽量薄。

**为什么自己写打包器**：项目要求"零安装 + 单文件 + 断网可用"，引入 Rollup/esbuild 会带来 `node_modules`。模块图很小，`tools/build.mjs` 这个迷你打包器足够且完全可控。

**为什么枚举集中在一处**：`AM4` 与 `am4` 这类字面量分裂会让插槽规则（E1）大面积误判。`src/core/enums.js` 是唯一来源，校验脚本会检查越界。

## 本期范围

**不含价格与预算**（M5 已推迟到 P1）。`tools/check-no-price.mjs` 作为门禁扫描界面代码与产物，确保不出现 ¥ / 总价 / 金额。
